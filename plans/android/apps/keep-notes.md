# Android / apps — Keep Notes

## Role + requirement refs
**Skills and engineering depth** as a board of notes. R23, R24. `AppRole: notes` · slug `keep` · owns `skills`.

## Portfolio mapping
`SkillsMatrix` + derived text, produced by the **same formatters as iOS Notes** (shared generators; different
presentation). One note per skill group plus summary notes:

| Note | From | Card look |
|---|---|---|
| 📌 **Skills — overview** | all groups, top skills | pinned, `primary-container` |
| 📌 **How I work** | person summary + recurring highlights | pinned, `tertiary-container` |
| One per `SkillGroup` (Languages, Frontend, Backend, Cloud, Tools…) | group items | checklist-style lines with a level bar, each group a different M3 container colour |
| **Stack by project** | projects × stack | list with links |
| **Currently learning** | skills with level ≤ 2 | only if non-empty |
| 📌 **Now** (`AND-KEEP-07`, `shared/23`) | `person.now.text` + "Updated {now.updated}" | pinned first, Keep's blue note colour (tone 2); label "Now"; one sentence per line |
Labels (Keep "labels") = the skill group ids → filter.

## Anatomy
- **Top search bar** (56 dp pill "Search your notes", leading ☰ → drawer with Labels; trailing **grid/list toggle** +
  avatar initials).
- **Board:** "Pinned" header then "Others"; a **staggered (masonry) grid**, 2 columns on phones — implemented with CSS
  columns (no JS layout); cards: 12 dp radius, 1 dp `outline-variant` border, title Title-M, up to 8 lines of content,
  label chips at the bottom.
- **Bottom app bar:** decorative action glyphs (checkbox, brush, mic, image — `aria-hidden`, disabled) + a **FAB "+"**
  docked at the right which, since the board is read-only, opens a small dialog: "This board is read-only — but you
  can write to me instead." → **Open Gmail**.
- **Note view:** the card **container-transforms** to full screen in its own colour; top app bar ◀ · pin (decorative
  state) · ⋮ (Copy link · Find in note); body Body-L; level bars (4 dp tall, `primary`) with text equivalents; footer
  "Edited {resume.updated}".

## Behaviour & states
| State | Behaviour |
|---|---|
| Open note | Card → full-screen container transform (300 ms); **Back** reverses into the card |
| Grid ⇄ list toggle | Session state; list = single column |
| Label filter | Drawer → label → board filtered; chip shows active label with ✕ |
| Search | Filters cards live (title + content); no results → "No matching notes" |
| Tap body text | Snackbar once per session: "Read-only — these are about me." |
| Links in notes | Project names open GitHub at that project |

## Navigation & routes
`/android/keep` only; open note/label/layout = session state (Back closes the note first).

## Motion
Container transform per above; board filter: cards fade-through (no masonry re-layout animation). FAB dialog: M3
basic dialog 150 ms.

## Responsive
Phone landscape: 3 columns. **Pad:** 4 columns + navigation rail with labels. Text respects Larger-text pref + zoom.

## Accessibility
Board = `ul` of links (reading order = DOM order: pinned first, then others, top-to-bottom per note — CSS columns
preserve DOM order for AT); note view is a document with headings/lists; level bars `role="img"` named
("TypeScript: 4 of 5, 6 years") + a "View as list" toggle rendering `SkillsMatrix` semantically; FAB named "New note".

## Edge cases
Very long group → card truncates at 8 lines with "…"; full content in the note view. No low-level skills →
"Currently learning" absent. Colour containers keep ≥ 4.5:1 text contrast (validated by the palette script).

## Not like the others
A **colourful masonry board with labels and a FAB** (iOS Notes: paper canvas, folders → list → note, dot meters;
desktops: VS Code workspace; Linux: `cat skills.txt`).
