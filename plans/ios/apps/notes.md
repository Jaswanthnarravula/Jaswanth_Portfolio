# iOS / apps — Notes

## Role + requirement refs
**Skills and engineering depth** as a set of notes — the natural place for them on a phone, where there is no code
editor. R23, R24. `AppRole: notes` · slug `notes` · owns `skills`.

## Portfolio mapping
`SkillsMatrix` + derived text. Notes are generated from data by formatters (no hand-duplicated facts):

| Note (pinned order) | Generated from | Form |
|---|---|---|
| 📌 **Skills** | `SkillGroup[]` | Headed sections per group; each skill a checklist-style line with a 5-dot level meter and years |
| 📌 **How I work** | person summary + recurring highlights | Short paragraphs + bullets |
| **Stack by project** | projects × stack | A table: project → technologies (links open GitHub) |
| **Currently learning** | skills with level ≤ 2 (if any) | Bulleted list; note hidden if empty |

## Anatomy
- **Folders (root):** large title "Folders": "All iCloud" → **Notes** (n).
- **Notes list (pushed):** large title "Notes", search field; "Pinned" section then "Notes"; rows: title (17
  semibold), date + first line (15 secondary).
- **Note (pushed):** warm paper-white (dark: near-black) canvas, title 28 bold, body 17 with Notes-style headings,
  checklists (static circles — **not interactive**), tables with hairlines, tag chips (#frontend …). Toolbar: share ·
  ⋯ (Copy link · Find in note).
- Level meter: five 8 pt dots, filled = accent, with a text equivalent ("4 of 5").

## Behaviour & states
| State | Behaviour |
|---|---|
| Open note | Push; URL stays `/ios/notes` (single-section app); note id is session state restored on return |
| Read-only | Tapping the body shows a small banner once per session: "These notes are read-only — they're about me, after all." |
| Find in note | Inline find bar (highlights matches; Enter cycles) |
| Tag chip | Filters the notes list to notes containing the tag |
| Links | Project names open GitHub at that project (app flight) |

## Navigation & routes
`/ios/notes` only.

## Motion
Push/pop per lifecycle; list → note uses the standard push (no custom flourish). No typing animations.

## Responsive
Pad: three-column split (folders · list · note). Landscape phone: two columns (list · note). Text respects "Larger
text" pref and browser zoom (rem-based).

## Accessibility
Notes are real documents: headings (`h3`+), lists, `<table>` with headers. Level meters are `role="img"` with names
("TypeScript: 4 of 5, 6 years") **and** a plain "View as list" toggle that renders `SkillsMatrix` semantically.
Static checklist circles are decorative (`aria-hidden`).

## Edge cases
No skills at level ≤ 2 → "Currently learning" absent. Many skills → groups collapse with "Show all". Find with no
matches → "Not found".

## Not like the others
Skills as **Notes with a paper canvas, pinned notes, dot meters and tables** (desktops use a VS Code workspace;
Android uses **Keep** — a masonry board of coloured cards with labels; Linux prints `skills.txt`).
